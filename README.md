
# House Price Prediction

## Project Overview

This project uses Machine Learning to predict house prices based on input features from a house price dataset.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Google Colab

## Machine Learning

The project includes:

- Data preprocessing
- Train-test split
- Feature scaling
- Linear Regression
- Model evaluation
- House price prediction using user input

## Project Workflow

1. Load the dataset
2. Explore and clean the data
3. Prepare features and target
4. Split the data into training and testing sets
5. Standardize the features
6. Train the Machine Learning model
7. Evaluate the model
8. Predict house prices using user input

## How to Run

Open House_prediction_model.ipynb in Google Colab or Jupyter Notebook and run the cells sequentially.
